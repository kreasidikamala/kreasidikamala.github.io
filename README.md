# Undangan Amelia & Zeus

Situs statis untuk GitHub Pages. Foto dan musik berada di `assets/`.

Formulir RSVP dan ucapan bersama menggunakan Cloud Firestore. Konfigurasi Web app sudah diisi. Ikuti [panduan Firebase](setup/FIRESTORE.md) untuk mengaktifkan Anonymous Authentication dan menerbitkan Firestore Security Rules **sebelum** perubahan formulir ini dipublikasikan. Tanpa pengaturan tersebut, pengiriman akan gagal.

Ucapan terbaru tampil langsung di undangan. RSVP hanya dapat dilihat pemilik project di Firebase Console.
